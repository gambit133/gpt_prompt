# 쌤플레이 · AI마당 선생님 모여라

**학습자료 프롬프트 sample 생성기** — 마음에 드는 예시 그림(쌤플)을 고르고 학년·과목·주제만 적으면,
ChatGPT에 붙여넣을 프롬프트가 완성됩니다. 설치도 가입도 없고, 입력한 내용은 어디에도 저장되지 않습니다.

**사이트 주소:** https://gambit133.github.io/gpt_prompt/
**사이트 소개:** https://gambit133.github.io/gpt_prompt/about.html

## 선생님께

수업 준비를 하다 보면 지도안, 학습지, 형성평가처럼 매번 비슷한 자료를 새로 만들게 됩니다. 학생도 시험 전마다 정리 노트와 암기 카드를 또 만듭니다.
ChatGPT에 이미지로 만들어 달라고 하면 빠른데, 어떻게 시켜야 원하는 모양이 나오는지가 늘 문제였습니다.

그래서 잘 나온 결과물 72가지를 쌤플로 모아 두고, 그 쌤플대로 만들어 달라는 프롬프트를 자동으로 써 주는 페이지를 만들었습니다.
선생님 수업 자료(지도안, 판서 계획, 발문, 활동지, 수준별 자료, 선수학습 진단, 도입·마무리 카드, 시험지, 채점 기준표, 연산 연습지, PPT 구성안, 수행평가 안내, 서술형 문항·채점 기준, 피드백 카드, 오답 유형 분석, 기초 보충 자료, 핵심 3가지 포스터),
학교·학급 운영(가정통신문, 휴업일 공지, 행사 포스터, 동아리 모집, 학급 규칙, 시간표, 상장, 안전 교육, 학급 소식지, 1인 1역, 준비물 체크리스트, 수학여행 안내, 학급 이벤트 초대장, 스승의 날 카드, 대입 원서 일정표, 시험 기간 일정표, 출입 금지 표지),
학습용(정리·요약 · 도식·표 · 이해 · 암기·점검)으로 나뉘어 있습니다. 예시 주제는 소나기, 메밀꽃 필 무렵, 서시, 진달래꽃, 춘향전, 흥부전, 홍길동전, 동백꽃, 운수 좋은 날, 관동별곡, 사미인곡, 청산별곡, 광야, 꽃, 별 헤는 밤 같은 문학 작품과 삼국 통일, 3·1 운동, 조선의 건국, 광합성, 부력, 상태 변화, 질량 보존 법칙, 곱셈 공식, 피타고라스 정리, 일차함수, 연립방정식, 현재완료, 불규칙 동사, 수요와 공급, 선거, 세계의 기후, 온돌의 원리(비문학) 등으로 다양합니다.

## 예시로 채우기

자료가 없을 때는 2단계 오른쪽 위 **✨ 예시로 채우기**를 누르세요. 첫 번째는 예시 이미지와 같은 내용이, 그다음부터는 과목·단원별 예시 조합(주제 + 학습 내용 + 가이드라인)이 차례로 들어갑니다. 쌤플마다 100개가 넘는 조합이 있어 클릭만으로 초안을 만들고, 필요한 부분만 고치면 됩니다.

## 찜 목록

카드 왼쪽 위 ♡를 누르면 찜 목록에 담기고, 상단 **♥ 찜 목록**을 누르면 찜한 쌤플만 모아 볼 수 있습니다. 찜 목록은 브라우저(localStorage)에만 저장되며 서버로 전송되지 않습니다.

## 세 단계로 끝납니다

1. **쌤플 고르기** — 첫 화면에서 그림을 누르면 크게 볼 수 있고, 어떤 자료인지와 이럴 때 좋은지가 함께 나옵니다. **이 쌤플 사용하기**를 누릅니다.
2. **간단히 적기** — 학년 · 과목 · 주제(필수)만 적습니다. 주제, 학습 내용, 추가 가이드라인은 칸마다 **예시 보기**에 과목과 쌤플에 맞는 예시가 있어 보고 고르기만 해도 됩니다.
   교과서 사진이나 학습지를 ChatGPT에 올릴 거면 **ChatGPT에 자료 첨부할게요** 토글을 켠 채로 두고, 올릴 자료가 없으면 끄고 **학습 내용**을 몇 줄 적습니다.
   필요하면 **세부 조정**에서 톤 · 색감 · 글꼴 · 삽화 · 글자량 · 비율 태그를 고릅니다.
3. **복사해서 붙여넣기** — **프롬프트 생성** 뒤 **프롬프트 복사**를 누르면 ChatGPT에 붙여넣는 순서가 안내됩니다.
   프롬프트를 붙여넣고, **예시 이미지 복사**(또는 저장)로 예시 그림도 함께 넣은 뒤 전송하면 같은 구성으로 새 자료가 나옵니다.

### 더 좋은 결과를 얻는 팁

- **예시 이미지를 꼭 함께 넣어 주세요.** 글로 쓴 설명보다 그림을 직접 보여 주는 쪽이 배치와 색감을 훨씬 잘 따라갑니다.
- **자료를 첨부하면 그 내용으로 정리됩니다.** 교과서 · 필기 사진, 학습지, 요약본, PDF · 한글 문서, 수업 PPT 중 있는 것을 올리면 프롬프트가 자료의 용어와 순서를 우선 쓰도록 지시합니다.
- **글자가 틀리면** "○○를 △△로 고쳐 줘"처럼 이어서 요청하면 됩니다.
- 주제에 **구운몽**(국어, 고등학교)을 적으면 예시 이미지를 실제로 만들 때 쓴 상세 지시문이 그대로 사용됩니다.

### 자주 묻는 질문

- **복사가 안 돼요.** 카카오톡 등 메신저 안에서 열렸다면 오른쪽 위 메뉴에서 **다른 브라우저로 열기**(Chrome, Safari)를 눌러 주세요. 이미지 복사가 막힌 기기에서는 자동으로 **예시 이미지 저장**으로 바뀌니 저장된 파일을 첨부하면 됩니다.
- **휴대폰에서 붙여넣기는 어떻게 하나요?** ChatGPT 입력창을 길게 눌러 **붙여넣기**를 선택합니다. 이미지는 입력창 옆 **+** 버튼으로 첨부해도 됩니다.
- **홈 화면에 추가할 수 있나요?** 브라우저 메뉴의 **홈 화면에 추가**를 누르면 앱처럼 아이콘이 생깁니다.
- **입력한 내용이 저장되나요?** 아니요. 모든 처리는 브라우저 안에서만 이루어지고 서버로 보내지 않습니다.

## GitHub Pages 배포

이 저장소는 **GitHub Actions**로 Pages를 배포합니다.

1. `Settings → Pages → Build and deployment → Source`를 **GitHub Actions**로 선택합니다.
   (워크플로 첫 실행 시 자동 설정을 시도하지만, 실패하면 직접 선택해 주세요.)
2. `main` 브랜치에 푸시하면 워크플로가 실행되고, 끝나면 `Actions` 탭 또는 `Settings → Pages`에서 주소를 확인할 수 있습니다.
3. 수정은 `index.html` 또는 `about.html`을 고쳐 커밋·푸시하면 됩니다.

워크플로 없이 쓰려면 `Source`를 **Deploy from a branch**로 바꾸고 `main` / `/ (root)`를 선택해도 됩니다.
`index.html`이 저장소 최상위에 있으므로 그대로 동작합니다.

## 로컬에서 열기

`index.html`을 더블클릭해 브라우저로 열면 됩니다. 이미지는 같은 폴더의 `assets/`에서 읽으므로 폴더째 두세요.

## 안내

- 웹페이지는 프롬프트를 **작성**만 합니다. 실제 답변과 이미지는 ChatGPT에 붙여넣어 생성합니다.
- 입력한 내용은 저장되거나 서버로 전송되지 않습니다.
- 예시 이미지와 해석은 참고 자료이며, 실제 수업 지문과 학교 평가 기준에 맞춰 확인하세요.
- 문학 개념 참고: [한국민족문화대백과사전 「구운몽」](https://encykorea.aks.ac.kr/Article/E0005948)
